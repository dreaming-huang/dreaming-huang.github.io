# Latin main fonts

Vendored for offline XeLaTeX compiles (`resume.cls` uses `Path = fonts/Main/`).

| File | Source | License |
| --- | --- | --- |
| `texgyretermes-*.otf` | [CTAN TeX Gyre Termes](https://ctan.org/pkg/tex-gyre-termes) | GUST Font License |
| `Fontin-SmallCaps.otf` | [exljbris Fontin](https://www.exljbris.com/fontin.html), same file shipped by the [billryan/resume](https://github.com/billryan/resume) template | Free for personal and commercial use (exljbris) |

Section headings use Fontin Small Caps. If you remove that file, change
`SmallCapsFont` in `resume.cls` to `texgyretermes-regular`.
