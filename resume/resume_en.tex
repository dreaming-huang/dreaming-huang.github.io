\section{\faCogs\ Project Experience}

\datedsubsection{
\textbf{Physically Based Facial Texture Generation In The Wild}}{Apr 2023 -- Apr 2025}
\vspace{-0.5ex}
\begin{onehalfspacing}
\begin{itemize}
\item
Collaborated with Kuaishou to develop a text-driven facial texture generation method based on progressive latent-space fine-tuning. Using the coupled texture dataset FFHQ-UV, we achieved high-quality, text-driven facial material generation with a flexible extension of the latent space. Without paired PBR supervision, the method still produces physically based facial texture maps; compared with the strongest prior methods in that year, generation quality improved by \textbf{20\%}. The work was summarized in a paper accepted to \textbf{\color{blue}{\large{TPAMI}}} (co-first author; first student author), with applications in virtual digital humans, film/VFX production, and related areas.
\end{itemize}
\end{onehalfspacing}

\datedsubsection{
\textbf{BuildingBlock: A Hybrid Approach for Structured Building Generation}}{Apr 2024 -- Apr 2025}
\vspace{-0.5ex}
\begin{onehalfspacing}
\begin{itemize}
\item
Collaborated with Tencent to develop a diffusion-guided, PCG-based structured building generation pipeline: (1) train a network to predict PCG-friendly layouts; (2) use text guidance to generate component details and invoke PCG for final building synthesis. The approach produces fine-grained, controllable, and interactive buildings; layout generation achieves \textbf{70\%} lower FID and \textbf{2$\times$} faster speed versus the strongest prior methods in that year. The work was summarized in a \textbf{\color{blue}{\large{SIGGRAPH}}} paper (first author), with applications in interactive game development, VR/AR, and architectural design assistance.
\end{itemize}
\end{onehalfspacing}

\datedsubsection{
\textbf{CG-MLLM: Captioning and Generating 3D content via MLLM}}{Apr 2025 -- Jan 2026}
\vspace{-0.5ex}
\begin{onehalfspacing}
\begin{itemize}
\item
Collaborated with Tencent to develop a large language model for understanding and generating 3D assets. We unify text, images, and 3D assets in a modeling-oriented MOT-based multimodal large model framework, strengthening spatial awareness so the model can both understand 3D content and end-to-end generate high-quality 3D objects, reaching SOTA for LLM-based 3D object generation and visual 3D understanding. The work was summarized in a \textbf{\color{blue}{\large{ICML}}} paper (first author), with applications in 3D asset creation and game development.
\end{itemize}
\end{onehalfspacing}

\datedsubsection{
\textbf{Integrated Intelligent Inspection Solution for High-Altitude Assets (Object Detection)}}{Oct 2021 -- Oct 2023}
\vspace{-0.5ex}
\begin{onehalfspacing}

\datedsubsection{
\textbf{Controlling Unconditional 3D Generation (3D Object Generation)}}{Nov 2022 -- Mar 2023}
\vspace{-0.5ex}
\begin{onehalfspacing}
\begin{itemize}
\item
This project aims to impose conditional control on existing unconditional generation methods by combining diffusion and GANs, and leveraging CLIP text--image alignment to conditionally control 3D generative models such as GRAF and StyleNeRF. Main components: (1) optimize CLIP-based control signals to steer GRAF/StyleNeRF generation toward text descriptions. (2) exploit CLIP’s text--image embedding correspondence: train with image embeddings as conditions on a W dataset, and at inference use text embeddings to control unconditional generators. (3) model-structure improvements and hyperparameter tuning.
\end{itemize}
\end{onehalfspacing}

\datedsubsection{
\textbf{Accelerating DiT with Consistency Models (Image Generation)}}{Dec 2023 -- Mar 2024}
\vspace{-0.5ex}
\begin{onehalfspacing}
\begin{itemize}
\item
This project aims to accelerate state-of-the-art DiT models by straightening denoising trajectories and optimizing denoising directions, enabling faster sampling with substantially improved image quality under few-step settings. Main components: (1) pre-encode training images with a VAE into latents to enable training under limited compute and speed up training. (2) integrate consistency models (CM) into DiT, outperforming the original DiT under few-step sampling and demonstrating CM’s effectiveness for DiT.
\end{itemize}
\end{onehalfspacing}

\datedsubsection{
\textbf{Octree-Based 3D Object Generation (3D Object Generation)}}{Apr 2024 -- Sep 2024}
\vspace{-0.5ex}
\begin{onehalfspacing}
\begin{itemize}
\item
This project builds graph/text-conditioned 3D diffusion models using octrees and sparse convolutions. We implement an octree-based 3D VAE with MinkowskiEngine to compress high-resolution objects for subsequent diffusion training; we extend MinkowskiEngine with self-attention, window attention, GroupNorm, LayerNorm, and other required modules to build a sparse-convolution denoising network. The pipeline supports VAE-based 3D compression/decompression and generating high-resolution 3D objects from low-resolution noisy latents.
\end{itemize}
\end{onehalfspacing}

\datedsubsection{
\textbf{Dual-Role Storyboard Image Generation (Image Generation)}}{Jul 2024 -- Oct 2024}
\vspace{-0.5ex}
\begin{onehalfspacing}
\begin{itemize}
\item
This project aims to generate images that match character identity and appearance. Building on an OMG + InstantID baseline, we generate images from dual-role story text and reference photos. Main components: (1) add an object-detection module to improve person localization, boosting YOLO-World + SAM mask quality. (2) add pose estimation, pose control, and clothing replacement modules, and use an LLM to detect conflicts between the prompt and these constraints, enabling pose and outfit consistency beyond face similarity alone.
\end{itemize}
\end{onehalfspacing}
